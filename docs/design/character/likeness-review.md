# Campus Workwear — likeness revision

Status: selected outfit A, likeness concept awaiting user review before model creation/integration.

The user supplied three personal HEIC photos and explicitly requested that the avatar's face match him. These photos are identity references for this edit. The earlier A concept supplies the outfit, adult body proportions and visual style.

Preserve from photos: facial proportions, cheek/jaw/chin shape, eyebrows and eye spacing, nose and side profile, lips and ears, swept dark hairstyle, and the actual short beard/moustache pattern. Preserve from concept A: forest overshirt, ivory tee/backpack, charcoal trousers, off-white sneakers and restrained matte rendering.

Raw photos are not copied into the repository or public website assets. JPEG format conversions for tool compatibility are stored outside the project under /private/tmp/portfolio-character-likeness/; the original HEIC files are unchanged.

The revision includes large face studies for likeness review. It is concept art, not a reconstructed/rigged model or a runtime replacement. Exact geometry, real-time detail and animation quality must be validated separately after approval.
